#📊 Dashboard de Análise de E-Commerce - Looker Studio

Este projeto consiste em um dashboard interativo desenvolvido no Looker Studio para analisar as principais métricas de um negócio de E-Commerce, como faturamento, comportamento do consumidor e faixas etárias.

## 🔗 Link para o Projeto
👉 [Clique aqui para acessar o Dashboard Interativo](https://datastudio.google.com/s/hP_uF2T0-to)

## 🚀 Tecnologias Utilizadas
* **Looker Studio** (para a criação dos elementos visuais e relatórios)
* **Google Sheets / BigQuery** 

## 🧠 O que foi desenvolvido:
* Criação de regras de agrupamento condicional personalizadas para segmentação de **Faixa Etária**.
* Desenvolvimento de cartões de visão geral (*Scorecards*) com design limpo e integrado.
* Filtros dinâmicos para análise de dados em tempo real.
